# Baozi Store - API REST

Trabalho da disciplina Desenvolvimento Web Back-End - UNINTER.

Aluno: Bruno Mathias Bordignon - RU 4879053

## Tecnologias

- Java 17
- Spring Boot
- Spring Data JPA
- Banco H2
- Postman

## Como executar

Abrir o projeto no IntelliJ e executar a classe `BaoziStoreApplication`.
A API roda em `http://localhost:8080`.

## Endpoints

| Método | Rota |
|---|---|
| POST | /clientes |
| GET | /clientes |
| GET | /clientes/{id} |
| DELETE | /clientes/{id} |
| POST | /produtos |
| GET | /produtos |
| GET | /produtos/{id} |
| DELETE | /produtos/{id} |
| POST | /pedidos |
| GET | /pedidos |
| GET | /pedidos/{id} |
| DELETE | /pedidos/{id} |
